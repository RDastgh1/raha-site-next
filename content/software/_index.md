title: "Software"
summary: "Open-source scientific software, computational infrastructure, and reproducible biomedical data science systems."
---

Software is treated here as a first-class research output: infrastructure that makes analysis reproducible, visual, inspectable, and useful for translational biomedical research.

MEAnalyzer anchors the software portfolio as a published, citable, downloadable MATLAB application. SciDataReportR extends the research infrastructure toward reproducible biomedical data analysis and reporting. The remaining domain packages and SciDataAgent are marked as in development so the site distinguishes established outputs from active directions.
